# Competitors, round 4 (research 2026-09-30)

Follows [market.md](market.md), [competitors-v2.md](competitors-v2.md), [sites gap analysis](2026-09-29-sites-gap-analysis.md), [modpacks round 3](2026-09-29-modpacks-round3.md), §22–24 of [features.md](../../product/features.md) and the [HUD visual redesign spec](../../specs/2026-09-29-hud-visual-redesign.md). It does not repeat them. Checked against our code on 2026-09-30: the client (`apps/web/client`), the modpack README (41 components), the manager README.

Since round 3 several items are already done and are left out here: conflict detection, named component sets (`TS1.` codes, `.tmset`), game-cache cleaning, the FPS cost badge and «Только лёгкие», sound preview, `gun_arc`, `bush_circle`, `battle_hits`, `arty_meter` (own vehicle only), `platoon_points`, `/ratings`, `/status`, `/play/guess-map`.

Method: WebFetch and WebSearch on 2026-09-30. SPA sites (tanks.gg, wotstat.info, blitzstats.ru) return an empty shell to WebFetch, so for them we cite GitHub or announcements. armor.wiki now redirects to a domain parking page, so it is gone as a competitor.

Hard filters as before: the mod handles only the player's own data and nothing about enemies in battle beyond what the client shows; Lesta ID only; no ads; Lesta attribution on every page.

Effort: S is up to a week, M is 1–3 weeks, L is more than a month.

### 2.2 Loading, motion, tables, mobile

- **Loading.** We already have skeletons (about 240 files) and `DataTableFallback`, so keep that. Two gaps:
  - no `loading.tsx` route boundaries, so navigation waits on the server with no instant shell. Add `loading.tsx` to heavy segments (`/p/[nick]`, `/t/[slug]`, `/tanks`, `/replays/[id]`) that reuse the page's own skeleton;
  - no stagger. Reveal the KPI tiles in sequence (30 ms step, `motion`, off under reduced motion).
- **Motion.** Add `<ViewTransition>` (Next 16 `experimental.viewTransition`) for:
  - list row → detail header (tank icon and name keep their place);
  - profile tab switches;
  - the compare tray chip → the compare page column.

  Keep durations at our tokens (160–200 ms).
- **Tables.**
  - Density toggle: already exists.
  - Add a sticky first column (name) on horizontal scroll on mobile, and a sticky header inside the page scroll. We use `position: sticky` in only 12 places; check `DataTable`.
  - Compare chips (above).
  - «Pin rows» from round 3 P0-4, if not done.
- **Mobile.**
  - In PWA standalone mode (`display-mode: standalone`), show a bottom tab bar (Поиск, Я, Отметки, Сессия, Ещё) instead of the drawer. The drawer stays for the browser.
  - Bottom sheet instead of a centred dialog for filters under 640 px. Base UI Dialog restyled; no new package.
- **Onboarding.**
  - First visit: a nick field on `/` with the fuzzy search we already have. It saves to «мои аккаунты» locally and the home switches to «мой дашборд» (recent, session, marks in progress). Login stays the path to private data (Lesta ID only).
  - First install of the mod: covered by the manager wizard.
  - First login: a 3-step checklist (bind the mod, set a goal, pick a playlist) with progress. No tours, no coach marks.

## 4. HUD and visual ideas not in the HUD spec

The spec covers team_hp, damage_log, hit_log, marks_panel, consumables, reload, loadout, sixth_sense, clock and the appendix. Missing:

1. **arty_meter and platoon_points have no visual spec.**
   - arty_meter: a vertical 0–10 «thermometer» with segment ticks, `color-warning` from 6, a stun glyph for stuns, and a day total in 11 px under it.
   - platoon_points: rows `[cls 16] Name ▮▮▮▯ 1 250 pts`, the own row highlighted, the total in `color-gold`. Put both in §6.
2. **Layout presets for the whole HUD**: «Минимум», «Стандарт», «Стример» (the panels clear of the usual webcam corners) as one click in the editor, plus a layout code `TH1.` next to the `TM1.` profile codes. Aslain's presets show players expect named selections ([Patreon, via search](https://www.patreon.com/Aslain/posts/biggest-quality-157646120)).
3. **Per-mode layouts** (see §3.2): the spec says event pages get no suppression. Add «в событиях показывать только: marks, clock, damage_log (compact)».
4. **Global HUD opacity and scale sliders** in the editor header (applied as one multiplier over the plate opacity and rem scale). Per-panel scale exists; a global one is missing.
5. **marks_panel sparkline**: the MoE percent over the last 10 battles as a 60×14 px SVG polyline next to the number. `marks_history` has the data.
6. **Live apply with undo** in the settings window: a change is visible at once on the preview panel, with a «Отменить (3)» chip and «Сбросить к профилю». Pattern from Aslain's Mod Menu ([GitHub](https://github.com/Aslain/modmenu)).
7. **Post-battle handoff**: when the player returns to the hangar, a toast-sized card (3 s, dismissable) with damage, the MoE delta and the session delta. It links to `battle_results` and needs no new data.
8. **Event-colour safety**: event maps such as the 1.45 ice map «Клондайк» ([update page](https://tanki.su/ru/update-1-45/)) are very bright. Add a live check that the plate at 55 % opacity still meets a contrast of 4.5:1 on snow, and raise it to 75 % for arctic maps (a list in config).

## 5. Manager and installer UX

- **First run.** Ours (game → preset → install) is already ahead of Jove's single exe and МОСТ. Add a «Что нового в этой версии» step only on updates, never on the first install.
- **Post-launch health.** After the game starts with a new install or update, read `python.log` for tracebacks under `net.triotmetki.*` and show «2 компонента не загрузились: …» with «Выключить» and «Сообщить». Nobody does this. МОСТ users post screenshots of broken mods instead ([thread](https://forum.tanki.su/topic/2205036-all-%D0%BC%D0%BE%D1%81%D1%82/page/162/)).
- **Update without re-downloading.** МОСТ advertises «installed mods are not downloaded again unless updated» ([announcement](https://tanki.su/ru/news/notifications/most-mt/)). Verify we skip packages whose sha256 is unchanged between releases, and say so in the update toast («скачано 1,2 МБ из 14»).
- **Offline and «no internet» states.** A МОСТ user saw «no connection» while the game worked ([thread](https://forum.tanki.su/topic/2205036-all-%D0%BC%D0%BE%D1%81%D1%82/page/162/)). Our error help should tell a blocked update host apart from no network and suggest the VPS URL check.
- **Guarded «Изменить набор».** Aslain saves presets in Documents so they survive updates, and our sets do the same. Also show a diff before applying a set («+3 компонента, −1»).
- **Browser → manager.** wotstat installs from the browser ([wotstat-analytics](https://github.com/wotstat/wotstat-analytics)). Our `?preset=` deep link exists; add «Открыть в менеджере» on each `/mod` component card (a `?component=<id>` deep link).

## 6. Things we already do better (keep)

- **Free team HP, marks history, artillery meter (own vehicle only) and platoon points.** Левша sells these in Plus ([modpack page](https://lebwa.tv/hub/modpack-lebwa)), and its «Артометр» may be tracer-based.
- **A manager, not a one-shot installer.** Snapshots, rollback, migration after a patch, signed releases, conflict detection, named sets, cache cleaning, FPS badges. Jove and PROTanki ship an exe; МОСТ lacks rollback and conflict details.
- **Fair-play transparency.** Every component carries a fair-play note. Lesta banned 50,882 accounts in one month for forbidden mods ([tanki.su, summer 2026](https://tanki.su/ru/news/notifications/chestnaya-igra-leto-2026/)), so this is a selling point. Put the ban figure and our «only your data» rule on `/mod`.
- **No ads, and API and coaching without commission.** tomato.gg shows ad banners and runs a commission marketplace ([tomato.gg](https://tomato.gg/), [marketplace](https://tomato.gg/blog/posts/pro-marketplace)).
- **Real MoE data** instead of estimates, marks history on the site and in the hangar, a free developer API.
- **Blog article pages** (author, date, TOC, share, RSS), ahead of Левша's blog (round 3 §7.1).
