# Три отметки — каталог фич

Название: **Три отметки** (otmetki). Название — наше, без символики Лесты.

Цель: один сайт, где есть всё, что сейчас разбросано по 15+ сервисам для «Мира танков» (Lesta, RU), плюс то, чего нет ни у кого.

Каталог собран по результатам исследования (сентябрь 2026): tomato.gg, kttc.ru, modxvm, wot-life, wotskill, tankist.net, lebwa.tv, protanki, poliroid, wotstat.info, tankistat.ru, tanks.gg, armor/map/replays.wotinspector, skill4ltu, mtreplays.ru, lesta-replays.ru, wotexpress, blitzstars, Belka, китайский клиент «坦克世界盒子» и др. Подробности — в [research/](research/).

## Обозначения

- **[GAP]** — на RU-сервере этого нет ни у кого или сделано плохо. Главные козыри.
- **[UNIQ]** — нет нигде, наша идея.
- **Фаза** — P1…P5, см. раздел «Фазы» в спецификации.
- **Источник** данных:
  - `API` — Lesta API;
  - `DB` — наша накопленная история;
  - `MOD` — наш мод-компаньон;
  - `REPLAY` — разбор реплеев;
  - `FILES` — файлы клиента;
  - `SCRAPE` — сбор с сайтов;
  - `USER` — ввод пользователей.

## 16. Мод-компаньон (P3)

- Python 2.7, пакет .wotmod, публикация через МОСТ и сайт.
- **Строго разрешённые категории**: сессия, отметки, итоги боя, свои выстрелы. Никакой информации о противнике сверх клиента.
- Функции:
  - шлёт итоги боя и события на наш сервер (пакетно, с подписью);
  - процент отметки в бою, «сколько урона не хватает»;
  - сессионная панель в ангаре;
  - автозагрузка реплеев;
  - привязка к аккаунту сайта одноразовым кодом.
- Даёт данные, которых нет в API: точные проценты отметок (из них — пороги), экономика, карты, очередь, сборки.

## 18. Developer API (P2 → P3)

- REST `/v1/*` + OpenAPI/Swagger, документация с примерами и песочницей («попробовать запрос»).
- Отдаёт то, чего нет в Lesta API:
  - WN8 и recent-периоды;
  - история игрока;
  - серверная статистика танков;
  - пороги отметок и их история;
  - тир-лист;
  - сессии.
- API-ключи в кабинете разработчика, графики использования, логи ошибок. **API бесплатен для всех**, платных тарифов нет. Лимиты по уровням (без цен, публичный `GET /developer/tiers`):
  - `free` — 10 000 запросов в сутки, 5 rps, 1 вебхук;
  - `plus` — 50 000 в сутки, 10 rps, 5 вебхуков: подписка Плюс повышает личные некоммерческие лимиты;
  - `community` — 2 000 000 в сутки, 100 rps, 50 вебхуков: бесплатно, выдаёт админ публичным бесплатным приложениям сообщества.
- Вебхуки: новая отметка, игрок закончил сессию, изменился состав клана.
- SDK: `@otmetki/sdk` (TS), `otmetki` (Python). Готовый data-provider для модов и OBS-виджетов.
- Витрина приложений сообщества, сделанных на нашем API.
- **Юридическое ограничение**: условия Лесты запрещают «коммерческое распространение данных API» и перепродажу API. Поэтому доступ к API не продаём; перепродавать наш API или закрывать его пейволлом запрещено условиями нашего API.

## 19. Аккаунт и монетизация (P3)

- Вход: Леста ID (OpenID), Telegram, email (magic link). Пароль от Лесты никогда не запрашиваем.
- **Три отметки Плюс** — единственное, за что берём деньги (подписка, YooKassa). Подробно — в [спецификации Плюса](superpowers/specs/2026-09-26-plus-subscription.md). Базовая статистика бесплатна для всех; Плюс продаёт нашу аналитику, мод- и реплей-данные, хранилище, ИИ и косметику, но не данные Лесты и не преимущество в бою:
  - полная личная история (бесплатно — 90 дней);
  - глубокая личная аналитика: полный разбор «почему я проигрываю», время суток и дни недели, тильт, патчи, кривая освоения танка;
  - советник по картам и взводам;
  - подробный разбор боя;
  - ИИ-тренер (бесплатно — 1 разбор в неделю, в Плюсе — до 5 в день);
  - трекер отметок Плюс: история процента по боям, «вечерний плейлист», рекомендации;
  - приоритетный сбор статистики (каждые 5 минут вместо 15);
  - уровни танков и испытания, валюта «Гильзы» (только зарабатывается), сезоны Плюса;
  - OBS-оверлеи Плюс: 20 оверлеев, премиум-темы, конструктор тем, виджеты;
  - косметика профиля (только на сайте);
  - лимиты: 10 аккаунтов, 10 целей, 300 отслеживаемых танков, 1 000 реплеев;
  - экспорт производных данных (сырые свои данные — бесплатно);
  - личные лимиты API;
  - ранний доступ к бета-фичам;
  - дополнения мода в ангаре (только ангар, после проверки МОСТ).
- Один план, три периода: месяц — 199 ₽, квартал — 529 ₽, год — 1 990 ₽.
- Пробный период 7 дней без карты: один раз на пользователя и один раз на аккаунт Лесты; для приглашённого по рефералу — 14 дней.
- Оплата закрыта флагом `PLUS.checkoutEnabled` (сейчас `false`), пока Леста письменно не подтвердит модель. Пробный период и промокоды работают.
- По окончании подписки всё, что создано в Плюсе, остаётся в режиме «только чтение»; при окончании ничего не удаляется (реплеи сверх бесплатной квоты хранятся 180 дней, см. спецификацию).
- Условия Лесты: в платном приложении реклама запрещена. Поэтому рекламы нет нигде и ни у кого.
- Реферальная программа, промокоды.

## 20. UX и дизайн (сквозное, P1)

- Тёмная «броневая» тема (сталь, камуфляжный шум, акцент «раскалённый металл» / «трассер») и светлая тема.
- Свой набор иконок: классы техники, нации, уровни I–XI, отметки, мастер, режимы. Анимированные SVG.
- Анимации (motion):
  - счётчики чисел «накатываются»;
  - графики прорисовываются;
  - отметки «вспыхивают» при получении;
  - плавные переходы страниц;
  - skeleton-загрузка в стиле «сканера».
- Микровзаимодействия: звуки интерфейса опциональны и выключены по умолчанию.
- Цветовые шкалы рейтингов (фиолетовый / синий / зелёный / жёлтый / оранжевый / красный), доступные для дальтоников (режим с узорами).
- Мобильная версия «из коробки», PWA, Mini App.
- i18n: ru (основной), en.
- Производительность: SSR и кеширование, страницы профиля < 1 с.
- Доступность: клавиатура, контраст, `prefers-reduced-motion`.

## 21. Админка и эксплуатация (P1 → сквозное)

- Админка: пользователи, подписки, модерация контента (гайды, сборки, реплеи), бонус-коды.
- Мониторинг сборщика: RPS к Лесте, очередь, отставание снапшотов, ошибки.
- Статус-страница сервиса и статус серверов игры.
- Фича-флаги, A/B.
- Политика хранения данных под условия Лесты (удаление по запросу, ретеншн).
