# Конкуренты v2: Левша и все остальные (исследование 2026-09-26)

Повод: «у Левши на сайте сборки на каждый танк, танки под ЛБЗ и т.д. — добавить всё, что есть у конкурентов».

Документ дополняет [market.md](market.md) и разделы §22–23 в [features.md](../features.md). Здесь:

1. что есть у каждого конкурента;
2. сводная матрица «фича → у кого есть → есть ли у нас»;
3. недостающие фичи, собранные в пакеты работ, с пометкой, какие подходят для Плюса.

Отмеченное *(не проверено)* взято из прошлых исследований или общих знаний, а не из живого просмотра страницы 2026-09-26. Многие сайты (tanks.gg, tomato.gg, wotstat.info) — SPA, WebFetch видит только оболочку.

## Жёсткие ограничения (фильтр для всех идей)

- **Lesta API.** Не собираем пароли и учётные данные Лесты: вход только через Леста ID (OpenID). Атрибуция Лесты. Никакой рекламы, пока есть платная подписка. Соблюдаем ретеншн и удаление по запросу. Не перепродаём сырые данные API.
- **Честная игра.** Мод читает и показывает только свои данные. Ничего о противнике в бою: ни ХП команд, ни «артометра», ни «оленемера», ни засвета.
- **Символика.** Никакой символики Лесты и официальных изображений — свои иконки (`@bronevik/icons`).
- **Чужой контент.** Не копируем чужие сборки, тексты гайдов и подборки «танков под ЛБЗ» — это авторский контент конкурентов. Строим своё:
  - сборки — популярные по телеметрии мода и реплеям, «что ставят топ-10%», плюс расчёт в нашем калькуляторе;
  - ЛБЗ — условия задач это игровые данные: парсим их из файлов клиента и храним сами, а подходящие танки рекомендуем по нашей статистике.

## 2. Сводная матрица

Столбцы:

- **Кто** — у кого есть: Л = Левша, NY = Near_You, NI = nidin, TN = tankist.net, KT = kttc, PO = poliroid, PT = PROTanki, TS = tankistat, WE = wotexpress, TG = tomato.gg, GG = tanks.gg, WI = wotinspector, WS = wotstat, MA = мобильные приложения.
- **У нас** — да / частично / нет, с маршрутом или модулем.
- **Источник**: API, DB, MOD, REPLAY, FILES, SCRAPE, USER.
- **Усилие**: S — до недели, M — 1–3 недели, L — больше месяца.

## 3. Чего не хватает: приоритеты и пакеты работ

Порядок — по «ценность для пользователя, пришедшего с сайта Левши / усилие».

Пометка **[Плюс]** означает, что расширенная часть фичи — кандидат на подписку. Принцип как у Dota Plus: платной бывает только премиальная аналитика и удобство; базовая статистика и базовая версия фичи — всегда бесплатно.

### WP-1 ★ «Как собрать танк»: рекомендованные сборки на каждый танк

Главная фича, которую просит пользователь.

- **Мод** (`apps/mod` + `mod/lib/contract`): добавить в `battle_result` необязательный блок `loadout` — только свой танк:
  - оборудование со слотами (включая спецслот);
  - снаряжение, директивы;
  - боекомплект по типам снарядов;
  - выбранные пары ПМ;
  - навыки экипажа по ролям.
  
  Это данные своей машины — укладывается в правила МОСТ. `Battle.loadout` уже есть в `sessions.prisma`; дополнительно пишем `bonus_type`.
- **Сервер**:
  - `builds`: расширить `popular-builds`:
    - отдельные распределения по каждой оси с долями и WR/уроном: каждый слот оборудования, каждый уровень ПМ, навыки по ролям с позицией изучения, снаряды, директивы;
    - когорты «все / топ-10% по нашему рейтингу `AccountTankRating`»;
    - режимы: рандом / Натиск / ЛФ по `bonus_type`;
    - минимальная выборка, а при нехватке данных — честный пустой стейт (без моков);
  - **«Рекомендованная сборка»**: наиболее популярный вариант у топ-когорты по каждой оси → собрать через `assemble-loadout` → пересчитать ТТХ → ссылка в конструктор. Помечать: «по данным N боёв за 30 дней»;
  - агрегаты считать в ночном воркере (collector/aggregates), новый `BuildUsageAggregate` (`db push`).
- **Клиент**:
  - новый маршрут **`/builds`** — каталог «Собрать танк»: фильтры нация/класс/уровень/роль/режим, столбцы «топ-сборка», «мастер», «95%», индекс потливости;
  - `/t/[slug]` — секция «Как собрать» вместо текущего `PopularBuilds`: вкладки «Рандом / Натиск», «Все / Топ-10%»;
  - `/builds/[tank]?preset=recommended` — открыть рекомендацию в конструкторе.
- **Данные**: MOD + REPLAY (реплеи тоже содержат лоадаут) + FILES (справочники).
- **Роли танков** из файлов клиента — фильтр для каталога (S, `gamedata/parsers/vehicle`).
- **[Плюс]**: «Моя сборка против реальности» (§23 #9); сборки топ-1% и конкретных стримеров-участников; сравнение двух популярных сборок бок о бок; история, как менялась мета-сборка по патчам. Базовая рекомендация и доли — бесплатно.
- Усилие: M (мод S, сервер M, клиент M).

### WP-2 ★ Хаб ЛБЗ с рекомендацией танков по нашим данным

- **Gamedata**: новый парсер `gamedata/lib/parsers/personal-missions`. Из XML личных задач клиента извлекаем:
  - кампании, операции, блоки наций и классы;
  - номера задач, основные и дополнительные условия («с отличием»);
  - допуск по уровню, награды, жетоны и приказы.
  
  Если условия в клиенте заданы ключами локализации — берём строки из `.mo` клиента. Это игровые данные, не текст конкурентов. Модели `PersonalCampaign`, `PersonalOperation`, `PersonalMission` в новом `missions.prisma`.
- **Сервер**: новый модуль `missions`.
  - `lib/condition-metrics`: маппинг типа условия → метрика: урон, засвет и ассист, заблокированный урон, фраги, выживание, ассист по гусле/оглушению, место по опыту в команде.
  - `lib/tank-fit`: ранжирование подходящих по нации и уровню танков по этой метрике из `TankServerStats` в когорте средних игроков. Выдаётся «вероятность» или индекс пригодности, а не авторский список.
  - `GET /missions`, `/missions/:campaign/:operation`, `/missions/:id/tanks`.
  - `/me/missions/:id/garage-fit` — «твои танки», через Леста ID `garage` и `account/tanks` + твои личные показатели на танке.
  - Прогресс: `UserEventProgress` → новая `UserMissionProgress` (ручные галочки «выполнено / с отличием»). Позже — свой прогресс из мода (своё состояние квестов).
- **Клиент**:
  - `/missions` — кампании и операции, прогресс к танку-награде;
  - `/missions/[campaign]/[operation]` — блоки наций × задачи, аккордеон, условия, «лучшие танки по данным», «из твоего ангара», галочки;
  - виджет в «Плейлисте вечера» (§23 #2) и в боте `/lbz`.
- **Данные**: FILES + DB + API private + USER / MOD.
- **[Плюс]**: синхронизация прогресса из мода; уведомление «на этом танке ты уже закрываешь задачу X» после боя; план «в каком порядке делать задачи, чтобы быстрее получить танк». Сами условия, рекомендации и ручной трекер — бесплатно.
- Усилие: M (основной риск — формат XML и локализации в клиенте Лесты; начать со спайка на 1–2 дня).

### WP-3 ★ Экономика и фарм танков

- **Сервер**: агрегат `TankEconomyAggregate` в `collector/aggregates` из `Battle` (мод) и реплеев. Медианы по танку:
  - доход, «чистые»: `factual_credits` / `original_credits`;
  - опыт;
  - отдельно с ПА и без (`is_premium`).
  
  Ремонт, снаряды и снаряжение — если мод их отдаёт; иначе оцениваем по FILES (цены снарядов × средний расход). Эндпоинты `tanks/economy`, `tanks/:id/economy`.
- **Клиент**:
  - `/tanks?view=economy` — таблица с переключателями ПА / резерв +50% / клановые выплаты, считается на клиенте;
  - секция «Экономика» на `/t/[slug]`;
  - `EconomyCalculator` подтягивает реальные медианы.
- **Данные**: MOD + REPLAY + FILES.
- **[Плюс]**: личная экономика аккаунта за 30 дней по своим боям; «окупается ли ПА и бустеры» (§23 #14). Таблица по танкам — бесплатно.
- Усилие: M.

### WP-4 Индекс потливости отметок и мастера

- **Сервер** `marks`: индекс = порог 95% (или мастера) ÷ медиана урона + ассиста на танке у когорты. Добавить поле в `moe-table.service`. Для мастера — через `TankPercentile`.
- **Клиент**: столбец и сортировка в `MarksTable` и на `/t/[slug]`; бейдж «лёгкая / тяжёлая отметка».
- **Данные**: DB.
- **[Плюс]**: нет — дешёвая бесплатная фича-магнит.
- Усилие: S.

### WP-5 ★ Витрина готового: страницы для модулей без маршрутов

Самый дешёвый способ закрыть половину матрицы wotexpress / PROTanki / tankist.

- **Клиент** (новые маршруты и views, логика в model-хуках):
  - `/codes` — бонус-коды: статус по отчётам, кнопка «работает / не работает»;
  - `/news` — новости и патчноуты;
  - `/shop` — акции + архив + «когда вернут»;
  - `/events` — календарь событий, боевой пропуск, Натиск, ЛФ, drops, iCal (§23 #12);
  - `/replays`, `/replays/[id]` — загрузка, разбор, 2D-плеер;
  - `/guides`, `/guides/[slug]`;
  - `/tactics/[id]` — планшет;
  - `/pulse` — пульс сервера;
  - `/platoons`, `/recruiting`, `/coaching`, `/tournaments`.
- **Сервер**: модули уже есть, возможно понадобятся публичные эндпоинты-списки.
- **[Плюс]**: пуш и Telegram-алерт по новому коду — бесплатно (это рост); для Плюса — «предзаказ» уведомлений о возврате конкретного танка в магазин с прогнозом и приоритетный опрос.
- Усилие: M суммарно (каждая страница S). Можно параллелить.

### WP-6 Сборки и мета под режимы (Натиск, Линия фронта, ранговые)

- **Сервер**: те же агрегаты WP-1 и WP-3 с разрезом `bonus_type`. Модуль `modes`:
  - тир-лист Натиска (`tanks/tier-list?mode=onslaught`, фильтр уже задуман в §4);
  - пороги лиг и «Легенды» сезона — вводятся редакцией или из API ratings, если доступно;
  - мета-танки сезона.
- **Клиент**: переключатель режима на `/tanks`, `/builds`, `/t/[slug]`; страница `/modes/onslaught`; калькулятор ЛФ в `/tools?calc=frontline`.
- **Данные**: MOD + DB + USER (редакция порогов).
- **[Плюс]**: личная статистика по режиму (свои WR, урон, очки рейтинга за сезон) — как мод «Статистика в Натиске» у Левши, но на сайте и только по своим данным.
- Усилие: M.

### WP-7 Каталог «где взять танк» и статусы техники

- **Gamedata / сервер**: флаги из файлов клиента — прем, коллекционный, наградной, исследуемый. Источник получения (магазин, Сборочный цех, ЛБЗ, боевой пропуск, облигации, событие) — редакционная таблица `VehicleSource` с датами и ссылками на `PremiumOffer` и `GameEvent`.
- **Клиент**: фильтр статуса на `/tanks` и `/builds`; блок «Где взять» на `/t/[slug]` с историей акций (`shop/offers/archive`).
- **[Плюс]**: нет (дополнительно — алерт «танк вернулся в продажу» бесплатно, прогноз — в Плюсе).
- Усилие: S.

### WP-8 Взводные состязания «по очкам» и турниры

- **Сервер**:
  - `tournaments` + `streamers/challenge-evaluator`: формат «взвод против взвода по сумме очков за N боёв»;
  - формула очков настраивается организатором (урон, фраги, засвет, победа);
  - проверка — только свои итоги каждого участника через наш мод или API; никакой информации о противнике.
- **Клиент**: `/tournaments`, `/tournaments/[id]` — регистрация, таблица, лайв-оверлей для стрима.
- **[Плюс]**: создание своих приватных турниров и челленджей для клана или стримера (клановый тариф); участие — бесплатно.
- Усилие: M.

### WP-9 Следить за многими игроками (как «Статометр»)

- **Сервер** `notifications` + `social`: дайджест «избранные за сегодня» (сессии, новые отметки), пуш каждые N часов, Telegram `/watch`.
- **Клиент**: `/me/watchlist`.
- **[Плюс]**: больше 10 отслеживаемых игроков и интервал 1 ч вместо 4 ч — удобство, не данные.
- Усилие: S.

### WP-10 Сложность освоения и роли (как у Near_You, но по данным)

Кривая освоения (§23 #10) → бейдж «Лёгкая … Хардкор»; роли из клиента. Фильтры на `/tanks` и `/builds`. [Плюс]: твоё место на кривой освоения. Усилие: M.

| Каталог чужих модов | Не наша задача, риски с безопасностью файлов |

## 5. Кратко

- У Левши три сильные вещи, которых у нас нет целиком:
  1. каталог «как собрать танк» по всем танкам с ПМ, навыками и долями использования;
